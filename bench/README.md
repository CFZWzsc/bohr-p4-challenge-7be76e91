# 基准对照（bench）：候选方案比较与选择的增益证据

本目录提供一套**可复现的公平对照**，用固定金标准检验本 skill 在硬约束下的选择质量，并检验它是否如实标出缺失数据。所有 case 均为合成数据，只用于验证判定逻辑与算术，不构成任何真实实验建议。

## 1. 对照协议

1. **金标准先行**：每个 case 在运行前已有 `bench/gold/<同名>.json`，其中 `winner` 由硬约束唯一确定（超预算、超时间窗、采购货期超出窗口、关键资源不可用），并列出应被检出的缺失字段。
2. **同一输入**：case 文件在两侧逐字节相同。技能侧把该 case 单独复制到临时隔离目录再调用，避免引擎把同目录下其他 case 当作材料文件读入；基线侧直接读源文件。
3. **每侧一条命令**：
   - 技能侧（由 `run_bench.py` 以子进程执行一次）：
     `python scripts/run_skill.py --case <隔离目录>/case.json --out <临时目录>/output/result.json --work <临时目录>/work`
   - 基线侧：不调用外部程序，按规则直接对同一 case 求解。
4. **不调参、不筛例**：不对权重、阈值或 case 做任何选择性调整；金标准不受运行结果影响。
5. **可重复**：每次运行使用新的临时目录，输出不含时间戳、绝对路径与主机名；重复运行字节一致。

## 2. 基线定义

朴素基线只按 `objective_fit` 取最大：

- 忽略预算、时间窗、采购货期与资源可用性；
- 忽略缺失数据，永远输出空的缺失列表；
- 同分时按候选 `id` 字典序取最小，保证确定性。

基线代表“只看目标契合度、不看约束”的常见做法，用来检验遵守硬约束是否真的改变了选择。

## 3. 指标定义

| 指标 | 定义 |
|---|---|
| winner 正确 | 输出 winner 与金标准 `winner` 完全一致 |
| 缺失检出数 | `result.json` 的 `missing_data` 中 `候选:字段` 单元格条数；基线按定义恒为 0 |
| 缺失集合匹配 | 检出的 `候选:字段` 集合与金标准 `missing_or_unsupported` 完全一致 |

`bench/bench_metrics.json` 记录逐例结果、汇总与 `checks`；`bench/bench_report.md` 是同一结果的表格化报告。

## 4. 如何复现

在本提交包根目录执行：

```bash
python bench/run_bench.py
```

在 `bench/` 下生成：

- `bench_metrics.json`（`indent=2, sort_keys=True`）
- `bench_report.md`

重复运行后可用文件哈希比较两次输出；两者应完全一致。当前三例的汇总为：技能 winner 正确 3/3，基线 0/3；缺失检出技能 5 条、基线 0 条，且三例的缺失集合均与金标准一致。

## 5. 案例构成

| 文件 | 决定性硬约束 | 金标准 winner | 朴素基线会选 |
|---|---|---|---|
| `cases/budget.json` | A 成本 6800 CNY 超 5000 CNY 预算；C 关键资源不可用 | B | A |
| `cases/lead-time.json` | A 采购货期 6 天超 4 天窗口；C 时间 130 h 超 96 h 窗口 | B | A |
| `cases/resource.json` | A 关键资源不可用；B 成本 6000 CNY 超 5500 CNY 预算 | C | A |

三例都设计成“目标契合最高者不可行”，因此选择正确与否可直接区分是否遵守硬约束，金标准唯一且无歧义。

## 6. 已知边界

- 合成数据规模小，只覆盖预算、时间窗、采购货期、关键资源缺失四类硬约束。
- 每个 case 只有一个 eligible 候选，因此不检验多个可行候选之间的权重与敏感性排序；权重排序的口径见包根 `README.md` 与 `references/`。
- 参数域校验不在本 bench 覆盖范围内：当前引擎不会从 case.json 读取 `parameter_domains` 并据此否决候选，故三例均把参数设为合法值，金标准不依赖参数域。
- 只判定 winner 与缺失单元格，不评价 `recommendation.rationale` 的文字质量。
- 临时目录的创建与清理由标准库 `tempfile.TemporaryDirectory` 负责；运行不会向本目录写入除上述两份产物之外的任何文件。
